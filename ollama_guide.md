## TO add new model in local
ollama pull <model_name>

## To remove any model from local
ollama rm <model_name>

## How to list all available local ollama model
ollama list

## How to start a chat session with ollama model
ollama run <model_name>

## Shows currently running models and their usage
ollama ps
